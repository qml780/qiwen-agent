# 《漆问》研究指标口径

本文件固定 MILESTONE 10 的研究日志口径。指标用于描述共创过程，不直接表示产品质量、文化准确性或玩家学习效果。

| 指标 | 定义 | 不代表 |
|---|---|---|
| 建议接受率 | `accepted / responded`；responded 包含接受、拒绝、修改后接受、继续讨论 | 智能助手建议质量或玩家满意度 |
| 修订次数 | 每类版本化 artifact 超出首版的版本数之和 | 编辑操作次数或代码提交数 |
| 试玩迭代数 | 状态为 completed 的 Playtest Session 数 | 游戏时长或独立玩家数 |
| 资产生成数 | visual / 3d / music Provider Job 数 | 被玩家采用的资产数 |
| 资产选择数 | 状态为 applied 或 undone 的 add_asset Unity 变更数 | 最终场景当前对象数 |
| 知识对应版本 | 含 alignment 字段的 concept 版本数 | 对应内容必然文化准确 |
| 游戏设计版本 | concept 与 logic 的版本数之和 | 完成质量 |

导出默认匿名化项目 ID；对话与反馈只输出角色、长度、评分和事件关系，不输出正文。生成脚本、模型思维过程、令牌、密钥、绝对用户目录和 Provider 原始请求均不得进入研究导出。
