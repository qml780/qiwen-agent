## 完成情况

- 玩家可在中文 Web 界面选择已批准三维资产、设置场景对象名称、预览加入场景、预览 Transform 调整，并从五个已测试模板中请求交互。

- 未批准的提议只写数据库，不接触 Unity。
- 玩家批准后，API 通过受令牌保护的 Local Bridge 调用 Unity；Unity 先复制当前 Scene 为 checkpoint，再执行变更并返回 receipt。
- 支持加入资产、调整位置/旋转/缩放、添加模板组件、写入受控生成脚本和配置交互。
- 支持拒绝、批准、失败回执和撤销；撤销同时恢复 Scene checkpoint，并只清理该变更在 `Assets/QIWEN/Generated/CoCreation` 生成的脚本。

## 安全边界

- Bridge 仅允许四种共创动作和 D/E 白名单工程路径。
- Transform 必须是有限三元数字，绝对值不超过 1000。
- 生成脚本最多 8000 字符，必须位于 `QIWEN.Generated` 命名空间；拒绝文件、网络、进程、编辑器、原生调用。
- Unity 组件只能从 M7 五个已测试模板的 allowlist 选择。
- 撤销只删除 receipt 指定且位于共创生成区的脚本，不接受任意路径。

## 联调中发现并修复

- 修复可选字段以 JSON `null` 传给 Bridge 时被误判为非法。
- 修复撤销只恢复 Scene、遗留生成脚本的问题。
- 修复 Test Runner 模式切换短暂 busy 的有界重试。
- 修复界面中的英文模板编号、资产前缀和状态，统一显示中文。
